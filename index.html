🚀 脚本系统 - 超越简单录制

使用强大的 GraalVM JavaScript 脚本系统，实现复杂的自动化逻辑：

// 根据屏幕颜色做出不同响应 mm.on('AfterRecordStopEvent', (event) => { let color = mm.getContext().getPixelColor(100, 200); if (color.getRed() > 200) { mm.log('检测到红色，执行动作 A'); } else { mm.log('未检测到红色，执行动作 B'); } });
⚡ 事件驱动 - 响应应用状态

监听应用事件，实现智能自动化：

// 应用启动时自动初始化 mm.on('OnAppLaunchedEvent', (event) => { mm.log('应用启动，自动加载配置'); }); // 录制完成时自动保存 mm.on('AfterRecordStopEvent', (event) => { mm.log('录制完成，共 ' + event.getActions().size() + ' 个动作'); });
