🚀 saMacros API 文档

完整的脚本编程参考指南

📌 当前版本： saMacros v2.0.0+ 兼容

欢迎

saMacros 提供了强大的脚本 API，允许开发者创建复杂的自动化脚本。本文档涵盖了所有可用的 API 接口、事件系统和最佳实践。

核心特性

  • Event System - 完整的事件系统，监听应用生命周期和用户操作
  • Context API - 访问系统信息、配置和屏幕数据
  • Macro Control - 完整的宏操作控制
  • I18n Support - 多语言国际化支持
  • System Integration - 深度系统集成能力

快速开始

// 脚本元数据
const registry_name = 'my_script';
const display_name = 'My Script';
const version = '1.0.0';
const author = 'Your Name';
const description = 'What this script does';

// 监听事件
mm.on('io.github.samera2022.samacros.api.event.events.BeforePlaybackStartEvent', 
    (event) => {
        mm.log('Playback starting with ' + event.getRepeatCount() + ' repeats');
    });

Script API (mm object)

主要脚本入口对象

概述

mm 对象是所有脚本的入口点，提供了事件监听、日志输出和上下文访问等基本功能。

API 方法

mm.on(eventClassName, callback) ✓ 已实现

描述： 注册事件监听器

参数：

  • eventClassName (string) - 事件类名
  • callback (function) - 回调函数，接收event对象
mm.on('io.github.samera2022.samacros.api.event.events.BeforePlaybackStartEvent', 
    (event) => {
        mm.log('Playback starting');
    });
mm.getContext() ✓ 已实现

描述： 获取脚本上下文对象

返回： IScriptContext - 包含系统信息和操作接口

const context = mm.getContext()
const config = context.getAppConfig()
const system = context.getSystemInfo()
mm.log(message) ✓ 已实现

描述： 输出日志信息

参数：

  • message (string) - 日志消息
mm.log('Script started')
mm.log('Action count: ' + count)
mm.cleanup() ✓ 已实现

描述： 清理资源（脚本禁用时自动调用）

注意： 通常无需手动调用

// 自动调用，但也可以手动调用
mm.cleanup()

Context API

脚本执行上下文接口

概述

Context 对象通过 mm.getContext() 获取，提供了访问系统信息、执行操作、显示通知等功能。

主要方法

context.simulate(action) ✓ 已实现

描述： 模拟鼠标或键盘操作

参数：

  • action (IMouseAction) - 鼠标/键盘动作对象
const action = new MouseClickAction(100, 100, 0, 0)
context.simulate(action)
context.getPixelColor(x, y) ✓ 已实现

描述： 获取屏幕上指定位置的像素颜色

参数：

  • x (int) - 像素 X 坐标
  • y (int) - 像素 Y 坐标

返回： Color - 颜色对象

const color = context.getPixelColor(100, 100)
if (color.getRed() === 255) {
    mm.log('Pixel is red')
}
context.showToast(title, message) ✓ 已实现

描述： 显示系统通知

参数：

  • title (string) - 通知标题
  • message (string) - 通知内容
context.showToast('Success', 'Macro completed!')
context.showToast('Warning', 'High repeat count detected')
context.getAppConfig() ✓ 已实现

描述： 获取应用配置对象

返回： IConfig - 配置接口

const config = context.getAppConfig()
const darkMode = config.getBoolean('enable_dark_mode')
const version = config.getString('app_version')
context.getSystemInfo() ✓ 已实现

描述： 获取系统信息对象

返回： ISystemInfo - 系统信息接口

const system = context.getSystemInfo()
const scale = system.getScale()
const isDarkMode = system.isSystemDarkMode()
context.getScreenInfo() ✓ 已实现

描述： 获取屏幕信息

返回： IScreenInfo - 屏幕信息接口

context.getMacroInfo() ✓ 已实现

描述： 获取宏状态信息

返回： IMacroInfo - 宏信息接口

context.getI18n() ✓ 已实现

描述： 获取国际化对象

返回： II18n - 国际化接口

context.getMouseInfo() ✓ 已实现

描述： 获取鼠标信息

返回： IMouseInfo - 鼠标信息接口

Configuration API

应用配置读取接口

概述

Configuration API 允许脚本读取应用的各种配置值。

获取配置对象

const config = mm.getContext().getAppConfig()

API 方法

方法 描述 示例
getBoolean(key) 读取布尔值配置 config.getBoolean('enable_dark_mode')
getInt(key) 读取整数配置 config.getInt('retry_count')
getDouble(key) 读取浮点数配置 config.getDouble('scale_factor')
getString(key) 读取字符串配置 config.getString('app_version')
getKeyMap() 获取所有配置（Map） config.getKeyMap()

使用示例

const config = mm.getContext().getAppConfig()

// 读取各种配置
const darkMode = config.getBoolean('enable_dark_mode')
const retryCount = config.getInt('retry_count')
const delayFactor = config.getDouble('delay_factor')
const version = config.getString('app_version')

// 使用所有配置
const allConfig = config.getKeyMap()
for (var key in allConfig) {
    mm.log(key + '=' + allConfig[key])
}

Internationalization API

多语言国际化接口

概述

I18n API 允许脚本获取已本地化的字符串，支持多种语言。

获取 I18n 对象

const i18n = mm.getContext().getI18n()

API 方法

i18n.get(key) ✓ 已实现

描述： 获取翻译字符串

参数： key (string) - 翻译键

返回： string - 翻译后的文本

const startText = i18n.get('main_frame.start_recording')
mm.log('Start button: ' + startText)
i18n.hasKey(key) ✓ 已实现

描述： 检查翻译键是否存在

参数： key (string) - 翻译键

返回： boolean

if (i18n.hasKey('custom_key')) {
    mm.log(i18n.get('custom_key'))
}
i18n.getCurrentLanguage() ✓ 已实现

描述： 获取当前语言代码

返回： string - 如 "en_us", "zh_cn"

const lang = i18n.getCurrentLanguage()
mm.log('Current language: ' + lang)

使用示例

const i18n = mm.getContext().getI18n()

// 获取当前语言
const currentLang = i18n.getCurrentLanguage()
mm.log('Language: ' + currentLang)

// 根据语言显示不同的消息
if (currentLang.startsWith('zh')) {
    mm.log('欢迎使用 saMacros 脚本系统')
} else if (currentLang.startsWith('en')) {
    mm.log('Welcome to saMacros scripting system')
}

Macro API 提供对当前宏的访问和控制能力。

获取 Macro Info 对象

const macro = mm.getContext().getMacroInfo()

状态查询方法

macro.isRecording() ✓ 已实现

描述： 检查是否正在录制

返回： boolean

if (macro.isRecording()) {

macro.isPlaying() ✓ 已实现

描述： 检查是否正在回放

返回： boolean

macro.isPaused() ✓ 已实现

描述： 检查是否暂停中

返回： boolean

描述： 获取操作数量

返回： int

const count = macro.getActionsCount()

Lifecycle Events

应用生命周期事件

OnAppLaunchedEvent

应用启动时触发。

mm.on('io.github.samera2022.samacros.api.event.events.OnAppLaunchedEvent', 
    (event) => {
        mm.log('App version: ' + event.getApplicationVersion())
        mm.log('Java version: ' + event.getJavaVersion())
    })

事件结构

OnAppLaunchedEvent
├─ getApplicationVersion()
└─ getJavaVersion()

Recording Events

录制过程中的事件

BeforeRecordStartEvent (Cancellable)

开始录制前触发。

BeforeRecordStartEvent
├─ getStartTime()
└─ getInitialMousePos()

AfterRecordStopEvent

停止录制后触发。

AfterRecordStopEvent
└─ getActionsCount()

OnInputCapturedEvent (Cancellable)

捕获到输入操作时触发。

OnInputCapturedEvent
├─ getInputType()      // 1=Press, 2=Release, 3=Wheel, 10=KeyPress, 11=KeyRelease
├─ getKeyCode()
├─ getX(), getY()
└─ getDelay()

使用示例

// 监听开始录制
mm.on('io.github.samera2022.samacros.api.event.events.BeforeRecordStartEvent', 
    (event) => {
        mm.log('Recording starts')
    })

// 监听停止录制
mm.on('io.github.samera2022.samacros.api.event.events.AfterRecordStopEvent', 
    (event) => {
        mm.log('Recorded ' + event.getActionsCount() + ' actions')
    })

Playback Events

回放过程中的事件

BeforePlaybackStartEvent (Cancellable)

回放开始前触发。

mm.on('io.github.samera2022.samacros.api.event.events.BeforePlaybackStartEvent', 
    (event) => {
        mm.log('About to play with ' + event.getRepeatCount() + ' repeats')
        // 可以通过 event.setCancelled(true) 取消回放
    })

BeforeStepExecuteEvent (Cancellable)

执行每个步骤前触发。

var stepCounter = 0
mm.on('io.github.samera2022.samacros.api.event.events.BeforeStepExecuteEvent', 
    (event) => {
        stepCounter++
        if (stepCounter % 10 === 0) {
            mm.log('Executing step ' + event.getActionIndex())
        }
    })

AfterStepExecuteEvent

执行每个步骤后触发。

OnLoopCompleteEvent

完成一个循环时触发。

mm.on('io.github.samera2022.samacros.api.event.events.OnLoopCompleteEvent', 
    (event) => {
        mm.log('Loop ' + event.getLoopNumber() + ' of ' + event.getTotalLoops() + ' completed')
    })

OnPlaybackAbortedEvent

回放中止时触发。

事件树

Playback Events
├─ BeforePlaybackStartEvent (Cancellable)
├─ BeforeStepExecuteEvent (Cancellable)
├─ AfterStepExecuteEvent
├─ OnLoopCompleteEvent
└─ OnPlaybackAbortedEvent

常用模式

常见的脚本编程模式

Pattern 1: 事件监控

// 监听回放开始事件
mm.on('io.github.samera2022.samacros.api.event.events.BeforePlaybackStartEvent', 
    (event) => {
        mm.log('Playback starting with ' + event.getRepeatCount() + ' repeats')
    })

Pattern 2: 状态检查

const macro = mm.getContext().getMacroInfo()

if (macro.isPlaying()) {
    mm.log('Macro is playing')
} else if (macro.isRecording()) {
    mm.log('Macro is recording')
} else {
    mm.log('Macro is idle')
}

Pattern 3: 条件执行

mm.on('io.github.samera2022.samacros.api.event.events.BeforePlaybackStartEvent', 
    (event) => {
        if (event.getRepeatCount() > 100) {
            mm.log('Warning: High repeat count')
            event.setCancelled(true)  // 取消回放
        }
    })

Pattern 4: 错误处理

try {
    const scale = mm.getContext().getSystemInfo().getScale()
    if (scale[0] < 1.0) {
        mm.log('Warning: Scale is less than 1.0')
    }
} catch (error) {
    mm.log('Error: ' + error.message)
}

Pattern 5: 功能检测

if (typeof mm.macro !== 'undefined') {
    // 使用 mm.macro API
    const count = mm.macro.getActionsCount()
} else {
    // 回退到事件型方法
    mm.log('mm.macro API not available')
}

Pattern 6: 配置缓存

// ❌ 不好 - 每次都查询
mm.on('io.github.samera2022.samacros.api.event.events.BeforeStepExecuteEvent', 
    (e) => {
        var quick = mm.getContext().getAppConfig().getBoolean('enable_quick_mode')
    })

// ✅ 好 - 缓存一次
var config = mm.getContext().getAppConfig()
var quick = config.getBoolean('enable_quick_mode')
mm.on('io.github.samera2022.samacros.api.event.events.BeforeStepExecuteEvent', 
    (e) => {
        // 使用缓存的配置
    })

故障排除

常见问题和解决方案

脚本加载问题

问题 原因 解决方案
脚本不加载 文件格式错误或元数据不完整 检查元数据格式，确保所有必需字段存在
脚本加载缓慢 脚本过大或有阻塞操作 优化脚本大小，避免在初始化时进行昂贵操作

事件问题

问题 原因 解决方案
事件不触发 事件类名错误或脚本未启用 验证事件类名，确保脚本在应用设置中启用
回调执行错误 回调中有异常 使用 try-catch 包装回调，添加日志输出

获取值问题

问题 原因 解决方案
获取 null 调用时机不对或对象不存在 使用 try-catch，检查值是否为 null
类型转换错误 获取的值类型与预期不同 使用正确的 get 方法（getInt vs getString 等）

权限和访问问题

问题 原因 解决方案
权限被拒绝 requires_native_access 未设置或白名单未配置 设置正确的元数据，确保脚本在白名单中

性能问题

问题 原因 解决方案
应用响应缓慢 脚本日志过多或事件处理器太重 减少日志输出，优化事件处理器
内存占用增加 未清理资源或内存泄漏 确保在 cleanup() 中释放资源

调试技巧

💡 调试建议：
  • 使用 mm.log() 输出调试信息
  • 在关键位置添加日志
  • 使用条件日志减少输出
  • 检查脚本是否启用
  • 验证事件类名的完整路径
